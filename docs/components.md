# 组件规范

## 会话列表项

```
┌─────────────────────────────────────┐
│ ┌───┐  通用助手            5分钟前  │
│ │ G │  点击开始聊天...               │
│ └───┘                               │
└─────────────────────────────────────┘
```

- 头像：48x48px，圆角 8px，背景 Primary
- 标题：16px，Semibold，单行截断
- 时间：12px，Muted
- 预览：14px，Muted，单行截断
- 分隔线：左边距 76px，高度 hairline

## 聊天气泡

### 用户消息
- 背景：Ink (`#141413`)
- 文字：暖白色 (`#faf9f5`)，15px
- 位置：右侧
- 形状：圆角 18px，右下角 6px

### AI 消息
- 背景：透明，与暖米色画布融为一体
- 文字：`#141413`，15px
- 位置：左侧
- 形状：无气泡边框，左右 16px 内容留白
- 内容：使用 Markdown 渲染；支持 `$...$` / `$$...$$` KaTeX 公式、`mermaid` fenced 图表和带语言标识的高亮代码块
- 安全：消息 HTML 不执行，远程图片不自动加载，图表和公式不依赖 CDN

│ │ 给 Mira 发消息...         ↑   │  │

- 输入区：暖白底 `#faf9f5`，边框 `#e8e6dc`，圆角 24px
