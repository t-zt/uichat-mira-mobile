# 设计原则

## 1. 简洁优先

- 暖米色 `#f5f4ed` 为浅色主背景，减少视觉噪音
- 信息密度适中，留足呼吸空间
- 避免多余装饰元素

## 2. 一致性

- 所有圆角统一体系（8/12/14/16/20px）
- 珊瑚色 `#c96442` 作为克制的品牌强调色
- 间距遵循 4px 基线网格

## 3. 移动优先

- 触控目标最小 44x44pt
- 底部输入框固定，键盘弹出时消息自动上推
- 会话列表使用单列布局，单手可操作

## 4. 状态可见

- 连接状态实时显示（顶部绿点/灰点）
- 加载状态明确（Loading 指示器、骨架屏）
- 操作反馈即时（按钮按下态、发送成功）

## 5. 可访问性

- 文字与背景对比度满足 WCAG AA
- 支持系统字体大小缩放
- 图标配合文字标签使用（避免纯图标歧义）

## 6. 明暗主题

- 保留浅色和深色两套主题，不用颜色反转替代深色设计
- 浅色主题使用暖米色画布，深色主题使用中性黑灰表面
- 品牌 Logo 保持固定的浅色 `#f5f4ed` 方形画布，不随主题反转
- 状态色在两套主题中分别满足可读性和 WCAG AA 对比度
